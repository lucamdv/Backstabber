# Backstabber Sprint 01 Implementation Plan

> For agentic workers: follow the test-first cycle and verify each deliverable before integrating.

**Goal:** Migrate local Backstabber gameplay to React while establishing a server-independent rules engine.

**Architecture:** React consumes projected game snapshots and sends revision-bound commands through an adapter. The local adapter owns rules and persistence, while the legacy entry points stay intact.

**Stack:** React, Vite, strict TypeScript, ESLint, Vitest and React Testing Library.

**Spec:** Backstabber Sprint 01 supplied in the task attachment.
